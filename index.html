Contabo Backup

Contabo Backup is a private utility used by its owner to store encrypted backup archives in an authorized Google Drive account. It is not offered as a service to the public.

How it works

Files selected for backup are encrypted before upload. The utility requests the Google Drive drive.file permission to create and manage files it creates or files explicitly opened with it. It does not request unrestricted access to all Drive content.

The utility is operated for a single owner's infrastructure. Google sign-in and authorization occur through Google's standard OAuth flow.
